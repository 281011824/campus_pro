一现状诊断

现在的“成长档案”本质上是一张学生表 + 一个弹窗 + 四类文本记录：能查、能记，但看不出“成长”，也支撑不了学期评价、实习就业和上级检查。

现状问题后果
名册 + 弹窗档案信息平铺，没有主线；打开后仍是表格与字段班主任看不到变化，学生没有成长感
只有特长、兴趣、奖惩、家访四类记录没有对接五育与中职职业素养，缺技能证书、实训实习、志愿服务、劳动教育学期评语、毕业档案、评优推荐缺少证据
记录是一条条文本没有维度、没有佐证、没有确认状态、没有学期归属无法汇总，也无法证明记录真实
只能班主任手工录入任课教师、企业导师、学生本人无法参与记录来源单一，班主任负担重
没有学期报告期末评语、综合素质评价、毕业档案都要另做集中突击补材料，质量不稳定
没有时间轴与对比看不到“比上学期进步在哪”评价只剩结果，缺少增值与激励
核心判断：问题不在页面样式，而在缺少一套面向中职学生的成长记录模型。继续在弹窗里加字段，只会把表格做得更长；必须重构为“维度 + 证据 + 学期 + 报告”的档案体系。

二外部成熟做法

以下做法分别来自省级政策、学校实践和成熟产品。我们只取适合中职、且能在现有 SQLite + 工作台架构下落地的部分，不照搬 K12 的“分数排名”和重运营玩法。

2.1 政策基线

来源核心框架可借鉴点
上海市《中等职业学校学生综合素质评价实施办法》（沪教委规〔2021〕5号） 道德与公民素养、技能与学习素养、运动与身心健康、审美与艺术素养、劳动与职业素养五个维度 写实记录 → 整理遴选 → 公示确认 → 录入系统 → 增值评价 → 形成纪实报告；每学期确认，毕业生成档案
山东省《中等职业学校学生综合素质评价实施方案》（鲁教职发〔2017〕1号） 思想品德、学业水平、艺体素养、职业素养、社会实践 学生自评 + 学校评价 + 整理遴选 + 审核公示；公示不少于 5 天，材料保存至毕业后 3 年，录入后不得修改
青岛市教育局《关于开展职业学校学生综合素质评价工作的通知》（2016） 思想品德与公民素养、身心健康、学业水平与专业技能、艺术素养、职业素养与实践能力 多元评价主体（学生、班主任、任课教师、同学、家长、企业、社区）；以学生个人成长档案为载体

2.2 学校实践

淮北树人中专“C5+12”

以品德发展、学业发展、身心发展、艺术审美、劳动实践五大板块为基础，细化为十二个具体项目，用结构化框架记录成长轨迹。

启示：维度不宜过多，关键是每个维度都有可记录的具体项目。

上海逸夫职校《成长手册》

设“道德规范园、文化技能园、成长健康园、职业规划园、实训实习园、成果分享园”等板块，从入学第一年就记录职业启蒙、实训实习与毕业实习评价。

启示：中职成长档案必须把“职业规划—实训—实习—就业”作为主线。

烟台机电工业学校成长档案

目录为：毕业生基本情况、思想品德、学业水平、艺体与劳动素养、职业素养、社会实践、过程性评价、学生自评与教师评语。

启示：档案要能直接打印成册，服务毕业与就业推荐。

上海贸易学校综评办法

每学期评价一次，内容为品德发展与公民素养、修习课程与学业成绩、专业技能与职业素养、身心健康与艺术素养。

启示：学期是评价的基本节奏，不做日排名。

2.3 产品做法

产品 / 方案值得借鉴的功能不适合直接照搬
科大讯飞“五育评价 / 育星图” 五育指标与活动一体化、雷达与数字画像、区校班生四级成长报告、成长手册、勋章激励、语音点评 重运营的活动库、硬件兑换、游戏化排行榜；我校当前不具备运营与硬件条件
新开普 K12 学生综合素质评价 20 个指标维度写实记录、评价方案配置、审核公示、PDF 成长档案、多主体填报 K12 的指标与班级评比逻辑；中职需替换为技能证书、实习实训、生涯规划
行业方案（综评全链路业务建模） 设置→评价→汇总→公示→归档全闭环；成长时间轴；学期报告自动生成；申诉复核；全程留痕 摄像头行为识别、消费画像等重采集；涉及隐私与伦理，暂不引入

2.4 提炼出的八条原则

  1. 写实记录优先：先有事实与佐证，再谈等级；没有证据就显示“证据不足”。
  2. 五维不合成总分：五个维度分开呈现，避免用一个人造总分掩盖结构性问题。
  3. 学期为节奏：日常随手记，学期整理遴选，生成一份可审核、可公示、可导出的成长报告。
  4. 中职有主线：职业认知、技能证书、实训实习、就业升学必须成为独立板块。
  5. 增值而非排名：只和学生自己的上学期比，不公布班级名次。
  6. 多主体但可控：任课教师、企业导师、学生本人可提交，班主任确认后才进入档案。
  7. 低负担录入：三步随手记、事件模板、Excel 批量导入，避免期末集中突击。
  8. 隐私与边界：心理明细不进档案；处分记录单独受控；家长电话、住址不入库展示。

三方案总览：一轴五维三阶

一轴是成长时间轴，五维是德智体美劳，三阶是中职三年的三个发展阶段。每名学生每学期形成一份《成长纪实报告》，记录有证据、评价有依据、毕业可带走。

3.1 一轴：成长时间轴

从入学到毕业，按时间沉淀关键节点：入学适应、第一次技能考核、社团与志愿服务、技能竞赛、1+X 证书、跟岗实习、顶岗实习、升学或就业。时间轴不是流水账，只收“有证据、有代表性”的事件。

3.2 五维：中职版五育

维度内涵典型记录数据来源
品德与公民素养理想信念、行为规范、诚实守信、责任义务、职业道德主题教育、志愿服务、好人好事、班级服务、处分（受控）政教处事件、班主任随手记、团委活动
学业与专业技能文化课、专业课、技能训练、技能竞赛、1+X 证书课程成绩、技能考核、竞赛获奖、证书、作品教务成绩、技能鉴定、班主任/任课教师录入
身心与健康体质健康、运动习惯、心理素质、健康生活体测、运动会、体育技能、心理课程参与体育组、校医室、心理中心（仅参与状态）
审美与艺体艺术课程、社团、文艺活动、审美表现艺术课程、社团、文艺演出、作品艺术教师、团委、班主任
劳动与职业素养劳动习惯、职业认知、实训实习、职业精神、生涯规划校园劳动、专业劳动、跟岗/顶岗实习、企业评价、职业规划实训处、企业导师、班主任

“职业成长”不单列为第六个评分维度，而是贯穿五维的主线：技能证书归“学业与专业技能”，实习实训与劳动归“劳动与职业素养”，生涯规划在学期报告中单独成段。这样既符合政策口径，又体现中职特色。

3.3 三阶：中职三年

第一阶段

适应期 · 第 1 学期

  • 建立档案，完成入学信息
  • 行为规范与学习习惯
  • 专业认知、职业启蒙
  • 至少 1 项兴趣或社团
第二阶段

发展期 · 第 2—4 学期

  • 技能训练与技能竞赛
  • 1+X 证书与职业资格
  • 劳动教育、志愿服务
  • 生涯目标逐步清晰
第三阶段

出师期 · 第 5—6 学期

  • 跟岗 / 顶岗实习记录
  • 企业导师评价
  • 就业推荐或升学准备
  • 毕业成长报告

3.4 评价方式

写实记录（主）

每条记录包含：维度、事件、时间、事实描述、佐证材料、来源、确认状态。没有佐证的记录可保留，但标注“待补证”。

等级评价（辅）

每维按 A/B/C/D 呈现，依据“记录覆盖 + 证据质量 + 班主任确认”，规则公开可解释；证据不足显示“未评”，不默认合格。

增值评价（激励）

只和本人上学期比，显示“进步 / 稳定 / 需关注”；两个学期都有数据才对比，否则显示“暂无对比”。

不做什么

不合成总分、不做班级排名、不公布百分位、不把心理测评和处分折算成分数、不用 AI 自动下结论。

四页面与交互

把“名册 + 弹窗”改成“班级成长驾驶舱 + 学生 360 档案”。班主任先看全班，再点开单个学生；所有记录都能回到时间轴与学期报告。

4.3 三个关键交互

随手记（3 步）

  1. 选维度与事件模板（如“技能竞赛”“志愿服务”“实训表现”）。
  2. 补一句事实：做了什么、结果如何，可拍照或上传证书。
  3. 保存为“已确认”或“待补证”；任课教师 / 企业导师提交的默认“待班主任确认”。

班级视图

  • 筛选：需关注、待补证、本学期无记录、实习中。
  • 展示：五维覆盖情况、记录条数、最近一次事件。
  • 批量：Excel 导入成长记录、批量提醒补证。

学期报告

  • 一键生成草稿：五维摘要、时间轴精选、教师评语建议。
  • 班主任编辑并确认，状态：草稿 → 待审核 → 已发布 → 已归档。
  • 导出 PDF / Word，作为评优、实习推荐、毕业档案附件。

证据与状态

  • 每条记录有来源、佐证、确认人、确认时间。
  • “待补证”集中提醒，不阻塞其他记录。
  • 发布后的记录修改需留痕，保留历史版本。

4.4 视觉与文案原则

  • 不用红黄绿给学生贴“好坏”标签；等级用中性色阶，问题用“需关注 / 待补证”描述行为。
  • 不出现“排名、百分位、击败了多少同学”等表述。
  • 空态写“暂无记录，可从一次班会或一次实训开始”，不摆示例学生。
  • 雷达图只在数据完整时出现；数据不足时用五条等级条，避免“假精确”。

5.1 等级规则（建议）

等级判定依据展示
A该维至少 4 条已确认记录，含 2 条以上标志性成果或高等级证据，且有明显进步“A · 表现突出”
B至少 3 条已确认记录，覆盖 2 个以上观测点，证据完整“B · 达到要求”
C有 1—2 条记录，或证据不完整“C · 需要加强”
D有明确负面事实且已确认（不含待确认事件）“D · 需重点帮扶”
未评该维记录少于 1 条，或全部待补证“证据不足，暂不评价”

规则由政教处审定后生效；系统只按规则汇总，不自行定性。等级不合成总分，不与班级排名挂钩。

6.3 与现有模块的衔接

  • 出勤、德育事件、成绩、作业不需要重复录入：按学生与日期自动归集到五维的“事实条”，由班主任在学期整理时遴选。
  • 成长档案只读引用 dom_* 与 students，不回写原始业务表，避免两套账。
  • 家校留痕仍走 todo_items，不进入成长档案正文；家访可另记一条“家访”成长记录。
  • 数据备份包新增“成长记录.xlsx”与“学期报告”目录。

七权限与红线

7.1 谁能看、谁能记

角色查看提交记录确认 / 发布
班主任本班全部可可确认、可生成并发布报告
任课教师所任班级学生（仅本课程相关维度）可提交“学业与专业技能”记录不可
企业导师所带实习学生可提交实习周记与企业评价不可
学生本人本人档案可提交自评与佐证（二期）不可
家长本人子女（只读，二期）不可不可
政教 / 校领导聚合统计；学生明细按现有规则不可见可登记德育事件处分记录受控

7.2 四条红线

心理明细永不入档

只记录“参与 / 未参与”心理课程或活动；测评分数、预警标签、咨询记录不进入成长档案，任何角色不可见。

处分记录单独受控

只有已生效处分进入“纪律记录”，仅班主任与政教处可见，不计入五维分数，不在班级公开展示，毕业处理按学籍规定执行。

不排名、不打总分

五个维度分开呈现；不生成综合素质总分，不做班级/年级排名，不向学生展示百分位。

发布即留痕

报告发布后冻结；确需修改时生成新版本并记录修改人、时间、原因；导出文件带版本号与水印。

八分期落地

先替换页面与记录模型，再补报告与证书实习，最后才引入学生、家长与企业端。每一期都能独立验收，不追求一次做完。

阶段范围交付出口条件
P0 页面重构 班级成长视图 + 学生 360 + 随手记 + 时间轴 替换现有弹窗；五维等级条；记录状态与待补证 班主任能在 3 次点击内完成一条记录并看到时间轴更新
P1 报告与证据 学期报告生成、审核、发布、导出；证书与实习登记 报告状态机；PDF / Excel 导出；历史版本 任意学生可生成一份五维报告并导出，发布后不可直接改
P2 多主体参与 任课教师提交、企业导师评价、学生自评、家长只读 待确认队列；权限与隐私开关；企微入口 外部提交默认待确认，班主任确认后才入档
P3 自动归集与增值 考勤、德育、成绩、作业、体测自动归集；学期对比 事实条自动生成；增值视图；数据缺口标注 未接入数据明确“暂不可用”，不估算、不补造

九验收标准

  • 班级视图可按“需关注、待补证、本学期无记录、实习中”筛选班主任代表
  • 学生 360 能同时看到五维等级、成长时间轴、证书与实习记录班主任代表
  • 一条记录包含维度、事实、时间、来源、佐证与确认状态政教处
  • “随手记”三步完成，移动端可用班主任代表
  • 任课教师 / 企业导师提交的记录进入待确认，不直接入档教务处
  • 学期报告可生成、编辑、审核、发布、导出，发布后冻结政教处
  • 五个维度不合成总分，页面不出现排名与百分位政教处
  • 心理明细、家长电话、住址不出现在档案与导出文件信息中心
  • 处分记录仅班主任与政教处可见，不计入五维政教处
  • 非本班班主任访问学生成长接口返回 403信息中心
  • 历史四类记录完整迁移，原创建人与时间不丢失信息中心
  • 2601—2617 班均可建立档案，无数据的班显示空态而非示例数据政教处
