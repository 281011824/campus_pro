02

目标架构

公网只看到主云的 443；台式机的 8000 端口只监听 WireGuard 地址。

为什么 web 只监听 10.66.0.4

若监听 0.0.0.0，校园网内任何机器都能直连 8000，绕过主云的 HTTPS 与访问控制。绑定隧道地址后，172.16.6.104:8000 不可达，入口只剩主云一条。

为什么 Redis 也只在台式机

请求与响应都在本机闭环，避免跨公网 Redis 带来的延迟和单点耦合；6380 独立实例不与系统 6379 的 requirepass 配置纠缠。

端口与信任边界

端口所在机器监听地址可达范围
443 / 80主云0.0.0.0公网 唯一对外入口
8000台式机10.66.0.4仅 WireGuard
6380台式机127.0.0.1仅本机
6379台式机127.0.0.1已有实例（带鉴权），本次不复用
51820/udp主云0.0.0.0公网可达，仅 WireGuard 协议

文件已放在 deploy/systemd/：htw-redis.service、htw-worker.service、htw-website.service。

04

主云 Nginx

完整配置见 deploy/nginx/htw.conf，以下是生效要点。

upstream htw_desktop {
    server 10.66.0.4:8000 max_fails=3 fail_timeout=10s;
    keepalive 16;
}

location / {
    proxy_pass http://htw_desktop;
    proxy_http_version 1.1;
    proxy_set_header Connection "";
    proxy_set_header Host              $host;
    proxy_set_header X-Real-IP         $remote_addr;
    proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header X-Auth-User       $http_x_auth_user;

    proxy_connect_timeout 3s;
    proxy_read_timeout    15s;
    proxy_buffering       off;
}
配置取值原因
proxy_read_timeout15sweb 端等 worker 的上限是 5s，15s 留足重试与抖动余量
proxy_buffering off关闭企微回调返回 text/plain 或 text/xml，避免缓冲改变响应时序
Connection ""置空配合 upstream keepalive，否则连接复用失效
X-Auth-User透传网关不伪造身份，见第 6 节风险
client_max_body_size8m常规业务请求远小于此，仅防异常大包

启用与证书

sudo cp deploy/nginx/htw.conf /etc/nginx/sites-available/htw.conf
sudo ln -sf /etc/nginx/sites-available/htw.conf /etc/nginx/sites-enabled/htw.conf
sudo nginx -t && sudo systemctl reload nginx

# 主云当前没有 certbot，需要先安装
sudo apt-get install -y certbot python3-certbot-nginx
sudo certbot --nginx -d htw.example.com
主云现在只监听 80，未监听 443；云厂商安全组需放行 443/TCP，否则证书签发与访问都会失败。DNS 的 A 记录要指向 124.221.26.96。

风险与待决事项

身份头可伪造（上线前必须处理）。 当前业务身份由请求头 X-Auth-User 决定，Nginx 只做透传。一旦公网可达，任何客户端都能自带该头冒充他人。正式开放前需在网关补一层真实身份注入（企微 OAuth 换取身份后由 Nginx 覆盖该头，或 auth_request 校验会话），并禁止外部同名头透传。
事项现状建议
website 脚手架依赖 MySQL 启动即初始化 db_async_session，需要 MySQL 可达 方案 A：台式机装 MySQL 8，零代码改动；方案 B：为工作台单独加环境变量跳过该初始化（改动约 5 行）。若近期不用量化业务，B 更省资源。
Python 版本 系统 3.10.12，依赖要求 ≥3.11 deadsnakes 装 3.12，或在 /opt/htw 下用独立运行时
台式机到存储 10.66.0.2 ping 不通（主云转发链未放行该方向） 不影响本次 Web 链路；如后续需要台式机访问存储，再在主云开放转发与防火墙
主云单点 公网入口只有一台主云 可接受；Nginx 侧已配 max_fails，台式机重启时短暂 502
校园网出口策略 台式机为 NAT 后主动外连，靠 25s keepalive 维持 若校园网封 UDP 长连接，握手会周期性断开，需观察 wg show 的 latest handshake
