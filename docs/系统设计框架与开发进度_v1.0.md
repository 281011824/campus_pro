## 二、分层架构

对齐架构文档 v1.0 的「接入 → 网关 → 应用 → 业务域 → 数据」五层，并补充运维视角：

| 官方分层 | 实现载体 | 职责 |
|---|---|---|
| ① 客户端层 | 校内终端、校外终端浏览器 | 校内直连；校外经云端加密中转 |
| ② 接入 / 网关层 | 校内 Nginx、云端 Nginx `:19002` | 静态资源、反向代理、访问门禁、主备 upstream、隧道转发 |
| ③ 应用服务层 | `website/app`（FastAPI） | 页面与接口、会话与鉴权、角色守卫与数据域、统一响应、审计留痕、文件导入导出 |
| ④ 业务域层 | `tasks/head_teacher_workbench/app/`（32 个 Python 模块） | 人员与账号、班级与寝室、学生主数据、德育量化、学情与成长、协同与秘书、巡查记录、写入与推送 |
| ⑤ 数据层 | SQLite（WAL）`runtime/dywork.db`、文件存储、热备份 | 主数据与审计表；导入导出文件；定时快照 |
| 运维层（补充） | systemd `htw-website`、`tools/db_audit.py`、`tools/db_sync.sh`、`_backup/<date>` | 双机进程管理、一致性审计、单向同步、备份与回滚 |

> 架构文档 v1.0 标注校内地址为 `172.16.6.104`，当前实际部署为 `10.66.0.4:5004`，以运维现状为准。

启动顺序（`website/app/main.py` lifespan）：`db.init_db` → `org.sync_directory` → `datadomains` → `moral_criteria` → `roster` → `growth_archive` → `seating` → `accounts` → `bindings` → `admins` → `classes` → `dorms` → `student_accounts` → `assistant`。

班主任端业务独立成包，`website` 侧只按固定路由清单接入（`FIXED_ROUTES / DYNAMIC_ROUTES / WECOM_ROUTES`），支持 worker + Redis 契约拆分，也支持当前线上的单进程模式。

## 五、数据与口径

**关键表**：`classes`（含 `major`、`head_teacher_userid`）、`students`（14 字段，主键 `class_id + student_id`）、`student_accounts`、`admins`、`school_accounts`、`head_teacher_pool`、`account_bindings`、`dorms`、`dorm_changes`、`student_transfers`、`inspection_records`（巡查台账）、`moral_criteria`、`dom_behavior`（含 `criteria_id / recorded_by / confirmed_by / confirmed_at`）、`growth_*`、`assistant_*`；**v1.9 学生成长导航 16 表**：`scales`、`scale_items`、`assessments`、`assessment_answers`、`scores`、`profiles`、`assess_batches`、`student_goals`、`student_plan_checks`、`student_todos_state`、`shares`、`share_access_logs`、`parent_accounts`、`parent_bindings`、`parent_grants`、`parent_bind_codes`。

**14 列学生字段**：学号、姓名、性别、专业、年级、班级、宿舍号、住宿类型、家长姓名、家长关系、家长电话、床位号、家庭住址、状态；姓名 / 性别 / 班级必填，学号可空自动生成。

**口径约束**（与基线 v2.0 一致）：
- 五维成长档案各维独立，不合成总分、不排名；德育量化分单独计算，不并入五维、不折算、不替代。
- 德育量化基准 100 分/学期，仅 `confirmed` 计分，`pending / void` 不计分，不公开学生排名。
- 指标分值以事件快照为准，改分值只影响新事件；停用指标不影响历史。
- 成长报告与导出物的学生载荷仅允许 `student_id / name / gender / class_id`。
- **v1.9 学生测评**：按维度独立给分（Likert 1..k、反向计分 `k+1-v`、多选题按选项维度），不合成总分、不做排名、不与德育分互算；画像只给优势 / 待发展标签。
- **v1.9 分享**：分享码只存 sha256，默认 24h、最长 7 天，可随时撤销；访客载荷仅白名单字段，不含学号、姓名全称、家长电话、原始作答与维度原始分；过期 / 撤销统一返回「分享已失效」。
- **v1.9 家长端**：独立会话 `role=parent`，只能访问绑定学生；只呈现正向成长与协同事项，不提供实时定位、聊天记录等监看能力；绑定码 10 分钟有效且一次性。
- 新增表 / 列一律幂等迁移（`PRAGMA table_info` 守门），重复启动不报错、不丢数据。
