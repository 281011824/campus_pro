## 二、八角色职责与数据域

权限模型为 RBAC：角色 × 操作 × 数据域，越域由服务端强制 403，前端仅作提示。

| 角色 | 职责要点 | 数据域 | 本期状态 |
|---|---|---|---|
| 管理员（ADMIN） | 人员与账号总台账、班级生命周期与班主任指定、系统配置与审计 | 全校 | 已上线（P0） |
| 政教处（DEYU） | 德育指标库、全校德育登记与统计、名单与学号编排、寝室统一分配 | 全校（班级字典只读、寝室可写） | P1 本期 |
| 班主任（HEAD） | 本班座位表 / 寝室表（同源）、学生信息维护、学情与德育总结、班主任小秘书 | 仅本班 | 已上线 |
| 科任教师（TEACHER） | 任教班成绩上传、课堂与作业点评、座位表只读 | 仅任教班与任教科目 | 待排期（P2） |
| 校领导（LEADER） | 全校学情与德育统计、重点班级标记与消息下发 | 全校只读（标记可写） | 待排期（P2） |
| 后勤（LOGISTICS） | 寝室 / 教室报修工单、楼宇与物资台账 | 楼宇物资，不接触学生敏感信息 | 待排期（P3） |
| 教官（INSTRUCTOR） | 军训、两操、仪容仪表与纪律巡查记录 | 住宿生范围 | 待排期（P3） |
| 寝管（DORM） | 归寝核查、寝室卫生与纪律评分、入住信息维护 | 住宿生范围 | 待排期（P3） |

## 四、不可破坏的 5 条红线

1. **数据不出校**：业务数据与账号数据只存校内服务器；校外访问仅经云端加密中转与只读备份。
2. **五维与德育量化分离**：五维成长档案各维独立，不合成总分、不排名；德育量化分单独计算，不并入五维、不折算、不替代。
3. **成长报告字段白名单**：报告与导出物的学生载荷仅允许 `student_id / name / gender / class_id` 四项，家庭住址、家长电话、心理明细一律不得出现。
4. **数据域收敛**：班主任仅见本班，政教处 / 校领导为全校域，科任教师仅见任教班与科目；越权一律 403 并留痕。
5. **迁移只增不改**：新增表 / 列一律幂等迁移（`PRAGMA table_info` 守门），重复启动不报错、不丢数据。

## 五、口径说明

- **五维 vs 德育量化**：两套体系互不折算。德育量化以「掌声鼓励（加分）/ 有待改善（扣分）」两方向指标累计；基准 100 分/学期，仅 `confirmed` 事件计分，`pending` / `void` 不计分，不公开学生排名。
- **指标分值快照**：事件保存登记时的分值快照；指标改分值只影响新事件，历史得分不变；停用指标不影响历史记录与统计。
- **成长报告白名单**：`student_id / name / gender / class_id` 四字段，由自动化测试持续守护，任何改动不得放宽。
- **降级不估算**：数据域未接入或口径未对齐时返回「暂不可用」，不用旧值、示例值或其他班数据顶替；未生成归寝数据不得当作未归。
- **试点班分源**：2607（66 人）与 2611 分源统计，不得混用或互相替代；唯一数据就绪日 2026-11-11。
- **档 B / 档 C 维持现状**：真实姓名脱敏与成绩域降级不解禁，保学预警不接入成绩域。
